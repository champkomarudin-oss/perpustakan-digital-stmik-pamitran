BAB 1

Pengenalan HTML

HTML adalah bahasa markup yang digunakan untuk membuat struktur sebuah halaman website. Dengan HTML kita dapat membuat judul, paragraf, gambar, tombol, tabel, link, dan berbagai elemen lainnya.

💡 Catatan: HTML digunakan untuk membuat struktur halaman. Tampilan website biasanya diperindah menggunakan CSS.

Apa itu HTML?

HTML merupakan singkatan dari HyperText Markup Language. HTML bukan bahasa pemrograman seperti C++ atau Python, melainkan bahasa markup untuk menyusun struktur halaman web.

BAB 2

Membuat Judul

Untuk membuat judul dalam HTML kita dapat menggunakan tag h1 sampai h6. 

<h1>Judul Utama</h1>

<h2>Sub Judul</h2>

<h3>Judul Kecil</h3>

Membuat Paragraf

Paragraf dibuat menggunakan tag <p>. Tag tersebut digunakan untuk menampilkan tulisan dalam bentuk paragraf. 

<p>
Saya sedang belajar membuat website
menggunakan HTML.
</p>

BAB 3

Membuat Link

Link digunakan untuk menghubungkan halaman website satu dengan halaman lainnya. 

<a href="halaman2.html">
    Buka Halaman 2
</a>
🚀 Tips Belajar: Jangan hanya membaca kode. Cobalah mengubah tulisan, warna, ukuran, dan isi kode kemudian lihat hasilnya di browser.
